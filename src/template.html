GeoGlyph combines project-authored interface code and assets with the open-source components and hosted fonts listed below. Third-party names and trademarks remain the property of their respective owners.

Application & embedded project assets

GeoGlyph Studio / U‑OS
Application HTML, CSS, JavaScript, interface design, canvas rendering, workflow integration and U‑OS SVG identity assets. Created by Josh Roberts for the Urban Operating System project.
Magic Eye artwork
magic_eye_qr.svg, magic_eye_qr_large.png, the embedded module matrix and payload are project-supplied assets used by the Magic Eye preview and export tools.
Unicode legacy-symbol mapping
Webdings and Wingdings conversion data is derived from Unicode WG2 N4384 / L2/12‑368, “Status of encoding of Wingdings and Webdings Symbols.” Source document.

JavaScript libraries

opentype.js 1.3.4
OpenType font parsing; bundled locally and available to the background font worker. Copyright opentype.js contributors; MIT License.
QRious 4.0.2
QR matrix generation; bundled for offline use. Copyright © 2017 Alasdair Mercer and © 2010 Tom Zerucha; GNU GPL v3.
jsQR
QR image detection and decoding; embedded for offline scanning. Copyright jsQR contributors; Apache License 2.0.
JSZip 3.10.1

pako

MapLibre GL JS 5.3.0 and polygon-clipping 0.15.7

Typography

Oxanium & Unbounded
Interface typefaces served by Google Fonts and distributed under the SIL Open Font License 1.1. Oxanium · Unbounded.
System and user fonts
Segoe UI Symbol, Segoe UI Emoji, Arial Unicode MS, Bahnschrift, Cascadia Code, Consolas, Wingdings, Webdings, Noto Sans Symbols and other scanned or user-loaded fonts are referenced from the user’s device. They are not embedded or redistributed by GeoGlyph; availability and licensing are controlled by the operating system, font vendor or user.

Browser-native HTML, CSS, Canvas, File, Font Access and File System Access APIs are platform features rather than bundled dependencies. Map tiles and optional interface web fonts require connectivity; font processing, QR generation, QR scanning and embedded application assets remain available in the standalone document.
