How to explore

Select a vehicle on the map, or open Vehicles and select a row. Its details will appear in the 5×7 pixel LCD ticker at the bottom. Select the bus, train or tram artwork in the header to filter the map to that vehicle type. Select the same vehicle again to show all types.

Use the map controls to refresh the data, choose a basemap or adjust vehicle and network layers.

Vehicle positions

Select a row to locate its vehicle and show its details in the ticker. Use Clear selection on the map to dismiss it.

Trip updates

Select a trip to locate its associated vehicle where available.

Service alerts

Select an alert to locate vehicles on affected routes.
